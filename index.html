📋 Main Loop Function

void followLine() - Core Control Logic
// Read 8 analog sensors and calculate weighted error for (int i = 0; i < 8; i++) { int value = analogRead(irPins[i]); sensor[i] = (value < IR_THRESHOLD) ? LOW : HIGH; int strength = (BLACK_IS_LOW) ? (IR_THRESHOLD - value) : (value - IR_THRESHOLD); if (strength > 0) { active++; weightedSum += (long)weights[i] * strength; totalStrength += strength; } } // Calculate error position float error = (float)weightedSum / totalStrength; // Sharp left corner detection (D1 & D2) if (sensor[0] == LOW && sensor[1] == LOW) { strongLeftTurn(); // Left: 5, Right: 140 return; } // Sharp right corner detection (D7 & D8) if (sensor[6] == LOW && sensor[7] == LOW) { strongRightTurn(); // Left: 140, Right: 5 return; } // PID-based correction for normal tracking float derivative = error - lastError; float correction = (Kp * error) + (Kd * derivative); int leftSpeed = constrain(NORMAL_SPEED + correction, 25, 110); int rightSpeed = constrain(NORMAL_SPEED - correction, 25, 110); driveForward(leftSpeed, rightSpeed); lastError = error;

⚙️ Motor Control Functions

Motor Speed & Direction Control
void leftMotorForward(int speed) { digitalWrite(AIN1, HIGH); digitalWrite(AIN2, LOW); ledcWrite(PWMA, speed); } void rightMotorForward(int speed) { digitalWrite(BIN1, HIGH); digitalWrite(BIN2, LOW); ledcWrite(PWMB, speed); } void strongLeftTurn() { leftMotorForward(5); // Inner motor (slow) rightMotorForward(140); // Outer motor (fast) } void strongRightTurn() { leftMotorForward(140); // Outer motor (fast) rightMotorForward(5); // Inner motor (slow) }

Control Logic

📍 SENSOR WEIGHTING

  • D1 (LEFT-MOST): -350
  • D2: -250
  • D3: -150
  • D4: -50
  • D5: +50
  • D6: +150
  • D7: +250
  • D8 (RIGHT-MOST): +350

🔴 SHARP TURN DETECTION

  • LEFT: D1 & D2 = BLACK
  • LEFT: Error ≤ -220
  • Action: L:5 R:140
  • RIGHT: D7 & D8 = BLACK
  • RIGHT: Error ≥ +220
  • Action: L:140 R:5

🟠 MODERATE TURN LOGIC

  • LEFT: Error ≤ -110
  • Action: L:25 R:105
  • RIGHT: Error ≥ +110
  • Action: L:105 R:25
  • Smooth transition before sharp turn

🧮 PID CORRECTION

  • Correction = (Kp × Error) + (Kd × ΔError)
  • Kp = 0.55 (Proportional)
  • Kd = 1.10 (Derivative)
  • Base Speed = 75 RPM
  • Left = Base + Correction
  • Right = Base - Correction

🎯 LOST LINE RECOVERY

  • If no sensors detect line:
  • Check lastError direction
  • If lastError < 0: Turn LEFT
  • If lastError > 0: Turn RIGHT
  • Search spiral pattern
  • Stop if no prior direction

⏱️ SPEED CONSTRAINTS

  • Normal Speed: 75
  • Turn Speed: 125
  • Inside Speed: 12
  • Moderate Outside: 105
  • Moderate Inside: 25
  • Range Limit: 25-110
